ЗАПУСК

Builds/Playtest/LaunchWindowed.command запускает MotelGame.app в окне 800×600.
Host: Create Private Lobby → передать invite code → дождаться игроков → Start Game.
Client: Join Private Lobby → ввести код. Обоим нужна одна версия игры.
В игре: [E] у основного компьютера → Reception → Start Shift.
Registration: имя, бронь, приехал ли на машине, номер машины. Вопросы о дороге
и цели поездки необязательны. Walk-in можно заселить без брони.
CCTV → Parking 1–7: сверить машину и физический номер с ответом гостя.
RoadWatch: ввести номер → SEARCH. Пробелы, дефисы и регистр несущественны.
Открыть фотографию нажатием на неё или OPEN PHOTOGRAPH; Escape закрывает
увеличенный снимок, следующий Escape возвращает в мотель.
После проверки — ADMIT в готовый номер либо REFUSE ACCOMMODATION.
Второй компьютер поддерживает общие вопросы, RoadWatch и CCTV; окончательное
решение принимает сотрудник у основного Reception. Остальная работа сохранена.

СЕРВЕР И ПОВТОРЯЕМОСТЬ

Только сервер выбирает случай гостя и решает, является ли он Mimic.
Признак Mimic и индекс текущего случая не передаются как игровой verdict.
Клиенты получают наблюдаемую внешность/машину, заданные вопросы и ответы.
Поиск возвращает один общий результат; одновременно пришедший устаревший
запрос поиска отклоняется по Revision. Повторный вопрос не дублирует ответ.
Сервер проверяет владельца/lease рабочего места, физическую близость, текущего
гостя и Visit, состояние смены, доступность номера и Cycle. Второй компьютер
не может заселить гостя через подменённый lease основного.
Активный разговор обновляет существующий таймер терпения гостя.

Расписание содержит один отчёт на пару прибытий со случайным порядком;
для нечётного количества получается floor/ceil половины. В нормальном лимите
3–8 гостей случаи внутри смены не повторяются. Обычная нагрузка M16.1 сохранена.
Результаты решений показываются в конце смены: отказ человеку — потерянное
заселение; новая экономика/репутация не добавлены. Живой подсказки «это Mimic» нет.

Допущенный Mimic идёт в назначенный номер как обычный NPC. Через 45 секунд
пребывания сервер убирает человеческую модель, коллайдер и NavMeshAgent,
освобождает комнату в Dirty для оборота и запускает существующий непрерывный
маршрут существа к вентиляции. Человеческого двойника не остаётся.
Отказавшийся гость уходит и не запускает угрозу. Сохранён один активный Mimic:
следующий допущенный экземпляр ждёт в комнате до завершения текущей угрозы.
Новая смена очищает регистрацию, поиск, машины и прежнее состояние охоты.

ОГРАНИЧЕНИЯ

Контент намеренно небольшой и фиксированный: после нескольких смен случаи
можно запомнить. Один активный Mimic, статические припаркованные машины.
30–60 секунд на решение — цель для человеческого playtest, не измеренный результат.
Охота проверена на естественном превращении, движении к вентиляции и exploration;
стрельба/полный бой в этом milestone повторно не прогонялись.
Приватное Relay-соединение проверяется на одном Mac с отдельными сохранёнными
тестовыми профилями. Новый вход с чистого компьютера и реальная удалённая сеть
друга остаются ручной проверкой. Windows в этом задании не пересобирался.
Старые Windows-файлы сохранены, но с новой версией online-игры несовместимы.
После открытия Unity убедитесь, что загружена Motel_Layout_V4; если Editor
предлагает Reload изменённой на диске сцены — используйте Reload.

config.uca.cloud.unity3d.com; один поздний наблюдатель завершил запрос с Curl 42.
Финальные Relay-прогон и запуск из Playtest не содержат таких ошибок.
