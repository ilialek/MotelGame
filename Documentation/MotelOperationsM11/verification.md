# M11 — проверка реализации

Дата: 25 октября 2026. Unity 6000.3.19f1, URP 17.3, NGO 2.13.3, Unity Transport 2.6.0. Сцена `Assets/Game/Scenes/Motel_Blockout_V3.unity`; build `Builds/Playtest/MotelGame.app`.

## Что проверялось

Тесты запускают отдельные настоящие standalone Host/Client процессы через Unity Transport/NGO. Персонажи перемещаются через CharacterController, действия проходят raycast / существующие RPC и серверные проверки, гости используют штатные NavMeshAgent и двери. Это автоматизированные игровые акторы, а не два человека за клавиатурой.

Состояния номеров, мешков, NPC, резерваций и сроки проживания не подменяются. Для воспроизводимости тестовые сценарии настраивают длительность/нагрузку до старта. В целевом сценарии аварии вызываются через валидируемую серверную операцию; в полном 900-секундном тесте их создаёт штатное расписание. Seed фиксирован, тип первых обычных запросов выбран для покрытия полотенца и TV.

- Unity импортировал и скомпилировал runtime + Editor код. Development build: **Succeeded, 0 errors, 0 warnings** (`build-validation.txt`). Отдельно выполнена компиляция Roslyn с установленными Unity/NGO assembly references.
- Сохранённая сцена открыта повторно штатным Unity Editor. Проверены четыре номера, точки мешков, четыре автомата, контейнер, carry-визуалы, ссылки на исходные Lights и отсутствие missing scripts (`setup-validation.txt`).
- NavMesh: 12 направленных маршрутов между входами номеров, подходы к контейнеру и панели имеют полный путь (`navigation-validation.txt`). Фактическое прохождение дверей и комнат проверяется runtime-сценариями.
- Проверены bounds новых объектов: нет пересечений с исходной активной архитектурой/мебелью. Осмотрены Editor previews панели, контейнера, номера со светом и без него; screenshots графического Host/Client содержат компьютер, мешок и аварию.

## Осталось проверить человеком

- Удобство обычного mouse/E/Esc управления и перехода компьютер ↔ first person; ощущение движения и читаемость новых сообщений.
- Положение мешка в руках/у другого игрока и возможное визуальное пересечение со стеной: нет IK или отдельного clipping prevention для carry mesh.
- Слышимость телефона, различимость аварийного затемнения и читаемость панели в реальном разрешении. Ambient/соседний свет намеренно сохраняются.
- Баланс работы двух людей на 15 минут. Автоматический актор не измеряет удовольствие, договорённости команды или новичковую нагрузку.
- LAN между двумя физическими компьютерами: проверен localhost, не сеть между устройствами. Сохранение, host migration, Steam/Relay и online lobby вне M11.

NPC ожидает, если игрок физически перекрыл маршрут; тест переселения специально проверяет последующее продолжение пути. Движение игроков остаётся owner-authoritative из M1; сервер проверяет действия по их реплицированному положению, без новой античит-системы.
