КАК ИГРАТЬ
Запуск: Builds/Playtest/LaunchWindowed.command (обычное окно 800×600).
Для совместной игры нужны одинаковые новые сборки. Create Private Lobby -> передать код другу -> Join Private Lobby -> Start Game у host. Старые сборки RoadWatch/M16 несовместимы с новым сетевым состоянием (версия motel-checkin-2).
Начните смену через главный reception computer / Room operations / Shift. Номера должны быть подготовлены. Гость приезжает по дороге, паркуется, выходит и идёт к стойке.
RESERVATIONS: слева автоматически видны портрет, имя, фамилия и DOB; справа бронь. Нажмите на доступное поле брони, затем ASK ABOUT ...; ответ появится под документами. Повторное нажатие читает прежний ответ.
ASK WHERE THEY PARKED сохраняет P01–P07. PARKING CAMERA: выберите соответствующее место, прочитайте номер на настоящей машине. ROADWATCH: введите номер вручную, SEARCH, при наличии отчёта ASK ABOUT REPORT. Фото открывается нажатием на изображение или OPEN PHOTOGRAPH; Escape закрывает его.
На основном компьютере выберите готовую комнату и ADMIT или REFUSE. Исследование необязательно. Второе рабочее место позволяет параллельно читать документы, спрашивать и пользоваться камерами/поиском; окончательное решение остаётся за главным reception computer. Ответы и последний результат поиска общие, выбранная вкладка и камера локальны.
Guest view показывает гостя с физического места игрока; Escape возвращает к компьютеру. Room operations / Shift сохраняет обслуживание, checkout и перевод комнат. Vent monitor сохраняет существующие камеры охоты.

ТЕХНИЧЕСКИЕ ГРАНИЦЫ
GuestCase хранит документы, содержательные вопросы и ответы, отчёт и portrait. RegisteredGuest реплицирует публичные данные визита и общий список ответов. RegistrationDesk проверяет workstation lease, текущий визит, текущий результат поиска и авторитетные решения. RegistrationPanel остаётся локальным представлением того же computer.
GuestVehicleJourney находится на существующем NGO NetworkObject гостя. Server продвигает машину по authored route; клиент интерполирует progress по тем же точкам. ParkingSlot задаёт пути, номер и выход водителя. Сервер пропускает одну машину по подъездной полосе, останавливает её перед коллайдерами и игроками. После парковки car collider и NavMeshObstacle препятствуют проходу сквозь машину. Камеры рендерятся локально, видео по сети не отправляется.
Визуал входа/выхода минимальный: дверь открывается, NPC появляется у водительской стороны / скрывается при посадке. Отдельной анимации пересаживания в салон и сидящего водителя нет. Трафика, рулевой физики и WheelCollider нет; машины появляются/исчезают на границах короткого существующего дорожного участка.
Для начального каталога обычная смена ограничена шестью уникальными случаями; порядок рандомизируется с примерно половиной отчётов. Старые Peter/Theo и legacy baggage assets сохранены для старых сцен, но не входят в активную V4. Старые RoadWatch docs относятся к предыдущему milestone; актуальный отчёт находится здесь.
Вопросы представлены текстовыми субтитрами, без новой озвучки или dialogue framework. Печатный номер в RoadWatch не заполняется автоматически. Состояние регистрации/ответы/результат поиска сохраняются при переключении вкладок и синхронизируются при late join. После смены гостя поле ввода и старый результат очищаются.
Windows в этой задаче не пересобирается. Лаунчер и предыдущие Windows-дистрибутивы сохранены; их старый сетевой формат не совместим с новой сборкой.
