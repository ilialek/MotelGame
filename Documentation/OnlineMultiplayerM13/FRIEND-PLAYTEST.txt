MOTEL GAME — M13 PRIVATE ONLINE PLAYTEST

Both players need the same version: motel-m13-1.

1. Extract the entire archive.
2. macOS: open MotelGame.app or LaunchWindowed.command.
   Windows: open MotelGame.exe or LaunchWindowed.bat.
   Keep the application's data folder and libraries beside it.
3. Wait for Online ready. No Unity account/login is needed.
4. Host: Create Lobby, then Copy Code. Send the code to your friend.
5. Friend: paste the code into Invite code, then Join Lobby.
6. Verify the player list. Host clicks Start Game.
7. Walk to the reception computer, press E, then Start Shift.
   This starts the 15-minute night.

WASD / mouse / Left Shift. Esc opens the lobby menu.
Resume Game returns to first-person control.
A client can Leave Lobby and rejoin with the same code while the host stays.
If the host leaves, the session ends. Create a fresh lobby/code.
After a night, start another shift at reception without reconnecting.

You need only the game and internet. No VPN, router setup or IP address.
Use your usual voice call; voice chat is not built into this prototype.

LOCAL TESTING
Launch LocalTestPlayer1 and LocalTestPlayer2 for two independent windows.
The launchers select separate cached player profiles. Players 3 and 4 are
available too. Don't run the same numbered launcher twice simultaneously.

MACOS NOTE
This test app has an ad-hoc signature, no Apple Developer ID or notarization.
If macOS blocks a trusted downloaded copy, try launching it once, then
System Settings > Privacy & Security > Open Anyway. Don't disable Gatekeeper.
Official instructions: https://support.apple.com/en-us/102445

IF CONNECTION FAILS
Check internet, same build version, fresh code and available lobby slot.
Use Retry Connection. If the host disappears, wait up to about a minute
for timeout/cleanup. Send the game log to the developer if it persists:
Mac: ~/Library/Logs/DefaultCompany/MotelGame/Player.log
Windows: %USERPROFILE%/AppData/LocalLow/DefaultCompany/MotelGame/Player.log

External cross-country latency and Windows runtime must be checked on the
actual remote machines. Tests on one Mac through Relay are not that proof.
