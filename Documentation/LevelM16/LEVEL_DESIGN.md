# M16 — Motel Layout V4

Новый уровень построен по схеме владельца проекта; прежний `Motel_Blockout_V3` сохранён как M15 fallback. Unity: 6000.3.19f1 / URP. Координаты: X — восток, Z — север, Y=0 — чистый пол, 1 unit = 1 m.

## План и размеры

```text
                         лес / низкая ограда
          BACKYARD, глубина ~7 м, dumpster на западе
   ┌───────────────────────────────────┬─────────────┐
   │             северный коридор      │ Maintenance │ → наружу
   │       ↓104       ↓105       ↓106  │    6×6      │
   │       104         105         106  └─────────────┘
   │        ↓           ↓           ↓
   │       открытый COURTYARD 17.2×11 м
   │        ↑           ↑           ↑             наружный
   │       103         102         101             проход
   │       ↑103       ↑102       ↑101       ┌─────────────┐
   └──────────── южный коридор ────┐        │   Storage   │
                        поворот   │   ↔    │    5×5.5    │
                             └────┼────────┴─── дверь ───┤
                                  │ Lobby 12×10           │
             PARKING              │ Reception / CCTV      │
                                  └──── главный вход ─────┘
                         дорога
```

Стрелки у номеров обозначают физические двери, а не одностороннее движение. Западный соединительный коридор связывает оба крыла и имеет выход во двор. Для доступа к любому номеру не требуется проходить через другой номер, Storage или Maintenance.

| Пространство | Чистые размеры / положение |
|---|---|
| Все номера | 5.6×6 м, потолок 2.8 м; существующие санузел, кровать, шкаф, стол, TV и уборочные взаимодействия |
| Южный ряд, запад → восток | 103, 102, 101; Z=0…6; X=0…5.6 / 5.8…11.4 / 11.6…17.2 |
| Северный ряд, запад → восток | 104, 105, 106; Z=17.4…23.4; те же диапазоны X |
| Коридоры | 2.8 м; южный Z=−3…−0.2, северный Z=23.6…26.4, западный X=−3…−0.2 |
| Lobby | 12×10 м; X=17.4…29.4, Z=−14.4…−4.4 |
| Storage | 5×5.5 м; X=24.4…29.4, Z=−4.2…1.3; непосредственно примыкает к Lobby |
| Maintenance | 6×6 м; X=17.4…23.4, Z=20.4…26.4 |
| Courtyard | 17.2×11 м; Z=6.2…17.2; небольшая центральная посадка 3.2×2.6 м |
| Backyard | около 7 м полезной глубины к северу от крыла; dumpster около X=−0.6, Z=30.9 |

Двор немного шире исходного рекомендованного диапазона 10–16 м: ширина определяется тремя полноценными комнатами и двумя межкомнатными стенами. Центральная посадка оставляет свободные маршруты вдоль обоих фасадов.

## Маршруты и обзор

Из Lobby — на запад через короткий переход, затем на север в южный коридор. Два сопряжённых участка стены закрывают обзор крыла; отдельной искусственной стены для перекрытия видимости нет. Проверена сетка точек внутри Lobby на высоте 1.65 м: прямых лучей к контрольным точкам обоих коридоров нет.

| Маршрут | Длина NavMesh | При ходьбе 4 м/с |
|---|---:|---:|
| Reception → 101, общественный маршрут | 16.54 м | 4.1 с |
| Reception → 104, общественный маршрут | 56.05 м | 14.0 с |
| Reception → 106, общественный маршрут | 67.62 м | 16.9 с |
| Reception → Storage | 8.16 м | 2.0 с |
| Reception → Maintenance, служебный shortcut | 37.30 м | 9.3 с |
| 103 → Dumpster | 29.49 м | 7.4 с |
| 106 → Dumpster | 24.15 м | 6.0 с |
| Maintenance → Courtyard | 18.68 м | 4.7 с |

Начало маршрутов Reception — первая точка очереди. Для мусорных маршрутов начало — внутренняя точка пребывания гостя. Время не включает открытие дверей, взаимодействия и остановки перед людьми. Маршруты сотрудников разрешают служебные и комнатные проходы; NPC используют общественные площади и только назначенную им комнату.

Storage даёт короткий служебный выход из Lobby во двор. Maintenance связывает северный коридор с наружным обходом к Backyard. Во всех номерах вторые двери выходят непосредственно во двор. Двери используют прежнюю политику доступа персонала; проход NPC временно резервирует конкретную дверь.

Низкая ограда оставляет видимым лес. Дорога ограничена видимыми ограждениями; лес — фон, не отдельная игровая зона. Машины остаются неподвижными placeholders.

## Интеграция

- Шесть самостоятельных `ServiceRoom`: уборка, мусор, полотенца, TV, электричество, заселение и turnover. Новый номер настраивается ссылками и `navigationArea`.
- Сохранены Player/CharacterController, NGO ownership, server-authoritative действия, Unity Transport и Relay. Протокол M16 отделён от несовместимой M15-сцены.
- `GuestLifecycle`: необязательное ограничение публичных маршрутов. В новом уровне отдельные области NavMesh для шести комнат и служебных помещений. Старый уровень сохраняет прежний режим.
- Переносимые предметы и убираемый мусор не создают постоянных отверстий в запечённом NavMesh. Открытая створка имеет необязательное динамическое препятствие; внутренняя точка ожидания NPC вынесена за её зону движения. NavMesh запекается с радиусом 0.4 м, оставляя запас относительно физических капсул на поворотах.
- Reception и отдельный CCTV используют существующий `ReceptionComputer` с независимыми сетевыми местами. Registration остаётся на основном компьютере. Сброс смены освобождает обе станции.
- Анализатор, содержимое багажа, вопросы и решения M15 сохранены. Полный сценарий содержит шесть прибытий и одного носителя.
- Полотенца и запасы — Storage. Шесть подписанных автоматов, приманка и пистолет — Maintenance.
- Сеть вентиляции: 20 связанных узлов, шесть комнатных ветвей, физические вертикальные соединения и три CCTV-камеры внутри каналов. Узлы привязаны к новой архитектуре.

## Работа со сценой

Открыть `Assets/Game/Scenes/Motel_Layout_V4.unity`. В Play Mode использовать существующее меню Host/Client или private online lobby. Начало обычной смены — на Reception; готовые ускоренные сценарии M15 остаются в development меню.

Для проверки вдвоём на одном Mac запустить `Builds/Playtest/LocalTestPlayer1.command` и `LocalTestPlayer2.command`. В обоих окнах выбрать `Local / LAN Debug`; в первом — `Start Host`, во втором — `Start Client` с `127.0.0.1`. Для сценария багажа и охоты Host может открыть F8 → `B · Complete gameplay — 10 minutes`. Для обычной смены с checkout и повторным обслуживанием использовать основной компьютер Reception; сценарий Complete намеренно продлевает пребывание гостей для охоты. Для онлайн-сессии — `Create Lobby`, затем `Join Lobby` по коду и `Start Game` у Host.

`Tools → Motel → Level V4 → Validate saved scene` проверяет ссылки, NavMesh, NGO IDs, обзор и движение створок. `Tools → Motel → Build Current Playtest` собирает новую сцену для macOS. Перестройка через Level V4 builder пересоздаёт именно V4, поэтому перед ручной правкой уровня не следует запускать её без необходимости. Исходная V3 не изменяется.

Точные результаты запусков и оставшиеся ручные проверки: `VERIFICATION.md`.
