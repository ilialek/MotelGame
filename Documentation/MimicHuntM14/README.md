# M14 — First Playable Mimic Hunt

Unity 6000.3.19f1 / URP / NGO 2.13.3 / Unity Transport 2.7.4 / Multiplayer Services 2.4.1.
No package changes. The scene is `Assets/Game/Scenes/Motel_Blockout_V3.unity`.
Current network compatibility identifier: **motel-m14-1**. Old M13 builds cannot join this version.

## Запуск на Mac

Стабильная сборка: `Builds/Playtest/MotelGame.app`. Оконный запуск: `Builds/Playtest/LaunchWindowed.command`.
Для двух окон используйте `LocalTestPlayer1.command` и `LocalTestPlayer2.command`: сохраняются отдельные Authentication profiles. Windows-сборки и старые архивы распространения не обновлялись.

Обычный сетевой вход сохранён: **Create Lobby → код → Join Lobby → Start Game**. Для локальной проверки без Relay: **Local / LAN Debug**, первое окно **Start Host**, второе **Start Client**, адрес `127.0.0.1`, одинаковый порт. Один Host подходит и для одиночной игры.

В Editor откройте основную сцену, включите Play Mode и используйте то же меню. Начало сессии не запускает смену: обычная 15-минутная смена начинается через reception computer, **E → Start Shift**.

## Быстрый сценарий

1. Хост открывает **F8** (на Mac при необходимости **Fn+F8**).
2. **Prepare quick playtest (8-minute shift)** запускает короткую смену, если смена ещё не идёт; подготавливает свободные комнаты и автоматически регистрирует двух гостей. Гости действительно приходят и проходят к комнатам через существующие двери. Не стойте во входе и дверных проёмах. Дождитесь двух состояний **InRoom**.
3. Выберите гостя-носителя, например проживающего в 102. Его текущий визит исключён из целей. Выберите исходный vent: 101–104. Кнопка **ACTIVATE MIMIC** запускает охоту. Для наблюдения пути на CCTV начните в комнате, отличной от комнаты потенциальной жертвы.
4. Закройте F8. На reception computer выберите **Vent CCTV**, переключайте **VENT CAM 1/2**. Это реальные виды двух соединений вентиляции; пустой кадр не означает отсутствия угрозы в других ветвях. **Reception** возвращает операции, **Esc** выводит из компьютера.
5. Приманка и пистолет стоят на новой небольшой полке в Utility за reception. **E** — взять. Они используют тот же единственный carry slot, что полотенце и мешок мусора.
6. Разместите приманку **G** на доступной поверхности у нужной решётки. Размещённая приманка светится; находящаяся в руках или на исходной полке не нагревает канал. **E** подбирает её обратно.
7. Стрелок берёт пистолет и готовится у решётки. **ЛКМ** — выстрел; **G** — положить пистолет. По умолчанию нужны три попадания. Следите за открытием решётки и физическим выходом существа. После смерти Mimic обычная работа мотеля продолжается.

Для solo сначала оставьте пистолет рядом с выбранным vent, затем принесите и разместите приманку, снова возьмите оружие. Можно обойтись без приманки и привлечь существо собственным теплом у решётки, но это опаснее.

## Эвакуация и неудача

Подойдите к находящемуся в комнате гостю, наведитесь на него и нажмите **E — Evacuate … to the lobby**. Гость проходит к двери и затем к своему месту в лобби; комната освобождается и становится Dirty, текущая заявка перепроверяется. Эвакуация учитывается после достижения лобби. Пока гость идёт, он остаётся уязвимым.

Чтобы увидеть неудачу, разместите двух гостей, выберите одного носителем и активируйте Mimic. Не вмешивайтесь. Существо предупреждает звуком, выходит и атакует другого гостя. В итог смены добавлены Guest deaths, Guests evacuated и Mimics eliminated.

Атака на сотрудника оглушает его на три секунды и заставляет уронить оборудование. Это временное ограничение движения, обзора и взаимодействия, без системы здоровья/воскрешения. Раненый Mimic может уйти обратно через ту же решётку с сохранённым HP.

**Force harmless fan complaint** создаёт обычную жалобу из 104. Там имеется регулярно дребезжащий и качающийся вентилятор. Его осмотр объясняет механическую причину звука; это не универсальный детектор отсутствия Mimic.

**Reset threat + return equipment (keep shift)** сбрасывает угрозу, оглушение и оборудование, сохраняя текущих гостей и итоги смены. Для полностью нового захода: **Finish current shift (debug)**, затем новая смена/Quick playtest. Обычное окончание и начало смены также сбрасывают M14.

## Правила и параметры

- Вентиляция: четыре комнатных узла, четыре вертикальных соединения и два общих junction; десять узлов в одном двустороннем графе. Между узлами существо движется непрерывно. Перенос в исходный узел разрешён только при явной debug-активации скрытого существа.
- Тепловое обнаружение: до 5.5 м **по графу**, приманка не дальше 2.1 м от выхода; игрок не дальше 1.65 м и видим из устья. Дальний vent не призывает Mimic через весь мотель.
- Скорость в каналах 1.1 м/с, на полу 1.65 м/с. До выхода — 9 с предупреждения. После выхода окно экспозиции до 12 с, первый замах не раньше 2.5 с; замах длится 1.6 с и повторно проверяет дистанцию и препятствия.
- Существо не уходит далеко от выхода: наземная цель должна находиться в радиусе 3.7 м. При провале возвращается по записанному наземному пути к тому же устью. После отступления 10 с не реагирует на тепло, чтобы не повторять выход немедленно; уязвимость от этого не меняется.
- HP 100, урон 34, минимальный интервал выстрелов 0.45 с. Сервер проверяет владельца, carry slot, актуальность состояния/номера выстрела, направление, оглушение и первый физический collider. Стены останавливают попадания. Friendly fire и боезапас отсутствуют.
- Смерть окончательна до явного reset или новой смены. Повторные попадания не увеличивают счётчик убийств. Носитель определяется сочетанием NPC и номера визита, чтобы повторно используемый NPC не защищал следующего постояльца.

## Код и интеграция

`Assets/Game/Scripts/Horror/`:

| Файл | Ответственность |
| --- | --- |
| `MimicHunt.cs` | Server state machine, граф, выбор целей, атаки, здоровье, evacuation RPC, debug setup |
| `VentNode.cs` | Физический узел, решётка, осмотр, обычный вентилятор |
| `HuntEquipment.cs` | Один предмет каждого вида, серверный подбор/размещение/выстрел, cleanup disconnect |
| `VentSurveillance.cs` | Две настоящие камеры и RenderTextures 384×256, включённые только при просмотре |
| `MimicPresentation.cs` | Силуэт, движения конечностей/челюсти, реакция на попадание, смерть |
| `GuestEvacuation.cs` | Подключение NPC к существующему E-interaction |
| `MimicDebugMenu.cs` | F8-инструмент только для хоста |

Существующие компоненты расширены точечно: `GuestLifecycle` — emergency phases и маршруты; `NightShiftController` — reset и итог; `TowelCarrier` — два новых вида предметов и stagger; `PlayerInteractor`/`FirstPersonController`/`ServiceInteractionValidation` — запрет действий при stagger; `ReceptionComputer` — вкладка CCTV и жалоба; `ServiceRoom` — явная debug-подготовка; `OnlineSessionController` — версия протокола.

Mimic использует server-authoritative `NetworkTransform`, значимые состояния — server-write `NetworkVariable`. Нового сетевого слоя, Rigidbody-синхронизации или отдельного interaction framework нет. Player movement сохраняет принятую ранее owner authority. У обычных клиентов нет debug UI с носителем и целью. Это не система защиты от модифицированного клиента: наблюдателю NGO нужны позиции сетевых объектов для отображения.

`Assets/Game/Editor/MimicHuntSetup.cs` добавляет корень `MimicHunt_M14`, назначает ссылки пяти NPC и проверяет сцену. Повторный **Tools → Motel → Mimic → Install M14** не перестраивает уже установленный M14. **Validate M14** проверяет ссылки, сетевые идентификаторы, NavMesh-выходы и эвакуационные маршруты. **Tools → Motel → Build Current Playtest** собирает только стабильный Mac output.

Новые материалы и оригинальные синтезированные короткие звуки находятся в `Assets/Game/Horror/`. Старые материалы/фурнитура/геометрия/освещение не заменены; добавлены локальные источники света именно для vents/CCTV. Новых сторонних ассетов или лицензий не добавлялось.

## Проверки и границы прототипа

Результаты конкретных запусков перечислены в `verification.md`. Development test actors включаются только явными `-motel-…-test` аргументами; обычный запуск их не создаёт. `Tests/run_hunt.py success`, `failure`, `evacuation`, `success --solo`; `--graphics` сохраняет кадры. Одновременно запускайте только разные режимы: каждому назначен свой LAN-порт.

Автоматические акторы двигают настоящий CharacterController, используют NavMesh, реальные коллайдеры, существующие взаимодействия и RPC. Это проверка связности и сетевого поведения, а не подтверждение интересности охоты или удобства ручного прицеливания. Внешний тест с двумя людьми должен отдельно оценить слышимость/направление звуков, понятность CCTV, темп предупреждения, прицеливание, читаемость выхода и смерти, а также задержку между разными машинами.

Текущая модель и анимация Mimic — процедурно собранный в Editor placeholder с длинными конечностями и челюстью; не финальный художественный ассет и не ragdoll. Гости после эвакуации ждут в лобби до конца смены, тела умерших сохраняются до reset смены. Компьютер по-прежнему обслуживает одного сотрудника за раз. Багаж, новые типы Mimic, экономика оружия, host migration и вентиляционный ремонт не входят в M14.
