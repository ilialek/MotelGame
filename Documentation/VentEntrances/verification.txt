Результат

Границы проверки
Финальный бинарный файл проверен полным сценарием входов и UI. Охота проверена на предыдущем кандидате до уточнения проверки видимого центра решётки; геометрия, MimicHunt, его настройки и остальное поведение взаимодействий совпадают. Версии Assembly-CSharp для каждого прогона указаны в tested-artifacts.json.
Это автоматизированные игровые сценарии в настоящих macOS/NGO-процессах, а не ручной плейтест ощущений. Подача движения в фоне вызывает тот же метод, который вызывается из обычного WASD Update; ввод Left Ctrl также выполнялся через Input System при наличии фокуса. В сценариях конкурентного доступа и безопасности Mimic используются явно выделенные тестовые перестановки участников и ускоренные таймеры. Они не входят в обычный игровой режим. Перемещение по самим рампам всегда идёт через CharacterController, без перестановки координат.
Первые неуспешные прогоны сохранены для диагностики: ожидающий тестовый Host перекрывал обычный путь Client в комнате; исправлена только расстановка тестовых участников. Проверка непрерывности Mimic перенесена в LateUpdate с явным DefaultExecutionOrder(10000), после MimicHunt (250), и учётом текущего frame delta, чтобы не сравнивать перемещение предыдущего долгого кадра с коротким текущим кадром при фоновой компиляции. Сам Mimic не изменялся.
Вручную остаются удобство поворота/прохождения друг за другом, субъективная темнота и ощущение управления в Editor Game View. Проход 1.10 м рассчитан на движение по одному; встречным игрокам нужно уступать. Windows executable, интернет Relay и задержки/потери пакетов в этой задаче не проверялись. Новая сетевая версия motel-underground-2: обоим участникам нужна новая совместимая сборка.

Как проверить вручную
1. Откройте Motel_Layout_V4 в Unity -> Play -> Host либо запустите указанный LaunchWindowed.command.
2. В Room 101 подойдите к низкой металлической решётке рядом с кроватью. Посмотрите на неё, E; персонаж должен остаться на месте.
3. Left Ctrl, затем WASD: спуститесь, развернитесь на площадке, дойдите до существующего тоннеля. F включает фонарь. Вернитесь тем же путём.
4. Для второго экземпляра повторно запустите launcher; Client -> localhost. Проверьте друг друга у решётки и в тоннеле, попытайтесь закрыть занятый вход. Для private online lobby обоим нужна версия motel-underground-2; данный прогон использовал локальный Unity Transport.
5. Повторите для остальных номеров и обычного обслуживания. Не запускайте повторно одноразовый Install wall entrances на уже мигрированной сцене.
